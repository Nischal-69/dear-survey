== Description ==

Dear Survey is a powerful and intuitive survey builder plugin for WordPress. Create beautiful surveys with ease using our modern, user-friendly interface.

**Features:**

* Easy-to-use survey builder
* Multiple question types
* Response tracking and analytics
* Email outreach capabilities
* GDPR compliant
* Customizable branding
* Responsive design

== Installation ==

1. Upload the `dear-survey` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to 'Dear Survey' in your admin menu to create your first survey
4. Use the shortcode `[dearsurvey id="X"]` to display your survey (replace X with your survey ID)

== Frequently Asked Questions ==

= How do I create a survey? =

Navigate to Dear Survey > All Surveys in your WordPress admin, then click "Add New Survey". Use the intuitive builder to add questions and customize your survey.

= How do I display a survey on my site? =

Use the shortcode `[dearsurvey id="X"]` where X is your survey ID. You can find the ID in the surveys list.

= Is the plugin GDPR compliant? =

Yes, Dear Survey includes GDPR mode which can be enabled in the settings.
